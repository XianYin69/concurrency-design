# 审查约束

整体审查（九项标准）得出的项目级约束，作为长期红线生效。

## 结构约束

1. 所有 `.md` ≤ 50 行（50 行红线只约束 markdown 文本；脚本不限行数，但仍禁裸 except、print 调试残留、>100 字符长行、超长函数）；超限即拆「入口 + 模块」。
2. 悬空链接 = 0（`scripts/check_links.py --root .`）。
3. 文件夹名 = 流程名；脚本英文命名。
4. SKILL.md 必含 YAML frontmatter；agent/ 四格式提示词一句话。
5. 缓存与临时产物不得写入 skill 目录（落 tmp 或用户缓存目录）。

## 行为约束

6. 不得跳过初始化；不得静默写盘（默认预览，`--yes` 才落盘）。
7. 不得删除 resistance/ 既有约束；新增须带违规后果与兜底。
8. 遇不明必联网学习并沉淀（见浏览器学习约束），禁止臆造 API。
9. 能力只经 dependence/ 声明获取（见薄技能依赖约束）。
10. 测试未全绿不得进入收尾；不得删测试换取绿灯。

## 度量约束

11. 逻辑链每步至少一条；过程链每步一存档；中断必须 resume 或上报。
12. 惩罚计数达 10 次即熔断，禁止继续盲试。

## 违规后果

- 结构违规 → 技能不可被解释器正确打包与遍历；
- 行为违规 → 不可回溯、用户信任损失；
- 度量违规 → 决策失去依据，复盘无从下手。
