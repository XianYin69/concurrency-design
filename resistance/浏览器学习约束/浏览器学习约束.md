# 浏览器学习约束

**红线**：遇到任何不明（未知 API、库行为、报错码、版本差异）必须先联网学习再继续，禁止臆造。

## 必须

1. 触发即执行：`python -B scripts/browser_learn.py --query "<问题>" --out tmp/learn`
   （内部派 file_ops 的 ff_lite.py search/fetch）。
2. 网络动作须 `:grant network`；未授权先向用户申请，不得绕过。
3. 取证结果须**蒸馏**：结论写入知识链（knowledge 链）+ `references/<领域>/<主题>.md`，
   并附 URL 与抓取时间。
4. 回原节点时在逻辑链记一条：`--from 不明点 --to 采用方案 --why 出处`。
5. 同一问题重复出现须复用既有取证，不得重复抓取浪费。

## 禁止

- 凭记忆书写未确证的函数签名、参数、返回结构或错误解释。
- 拿「看起来合理」的猜测通过测试（测试须验证真实行为）。
- 伪造检索结果或把未抓取的页面写成出处。
- 把整页受版权正文存入 skill 目录（只存摘要与出处）。

## 违规后果

- 臆造 API → 运行期报错、返工与用户信任损失。
- 无出处引用 → 知识链不可溯，后续无法复核。
- 绕过网络门禁 → 违反 SMS 高危操作红线（须 grant）。

## 兜底

- 网络不可用：记 `process_chain.py interrupt`，降级为本地 references/，
  并向用户明示「未联网确证」，禁止静默继续。
