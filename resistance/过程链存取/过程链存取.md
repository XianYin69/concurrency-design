# 过程链存取

流程状态外置：save 存档、interrupt 记中断、resume 恢复，跨会话可续。

## 必须

1. 每步完成即存档：
   `python -B scripts/process_chain.py save --step <节点> --data '{"k":"v"}'`。
2. 审查/测试失败先记中断：`interrupt --step <节点> --reason <事实>`，修复后 `resume --step <节点>`。
3. 状态文件落**用户缓存目录**（`<SMS_HOME>/cache/concurrency-design/`），禁止写入 skill 目录。
4. 收口前 `load` 复核：未解中断 = 0 才允许标记「完成」。
5. 返回机制：任一路径完成＝收口返回 SMS 主流程整合续排，不得以本技能完成结束整段对话。

## 禁止

- 静默吞掉中断（不记 resume 也不上报）。
- 把过程链当记忆唯一来源——关键结论仍须进逻辑链与知识链。
- 在 skill 目录留 `process_chain.json` 等运行时文件。

## 违规后果

- 无存档 → 会话中断后无法续跑，整条流程重做；
- 未解中断即收口 → 缺陷随交付进入生产。
