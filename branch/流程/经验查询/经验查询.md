# 经验查询
动手前先查既往经验，避免重复踩坑。
## 检索顺序
1. **链经验**：`chain recall`（memory/knowledge/logic 三链）查同类并发结论
   （锁序约定、池大小实测、竞态复现配方、取消语义坑）。
2. **本地知识库**：grep [`references/`](../../../references/references.md) 的内存模型/原语/模式/工具摘要。
3. **既往工程**：同仓 `CHANGELOG.md`、`tests/`、压测报告与提交（`git log --oneline`）。
4. **仍缺**：转 [浏览器学习](../浏览器学习/浏览器学习.md) 联网补齐，不得凭记忆臆造库行为或内存序。
## 动作
- 命中经验即引用其条目 id 写入逻辑链；无命中记 `--to 无既往经验`。
- 压缩上下文：`python -B scripts/context_compress.py --ratio 0.3 --kw <关键词>` 只留相关片段。
- 特别注意**跨语言类推陷阱**：Java 的 `volatile`、C++ 的 memory_order、Go 的 channel
  语义不可互推，既往经验须标明适用运行时。
## 产出
- `logic_chain.jsonl` 经验条目 + 本次采用的方案候选清单（≥2 个，供分支分析取舍）。
