# 背压与限流（并发系统的过载控制）

来源：[本地]（未联网确证）· 用途：防止并发放大成雪崩。

## 背压（backpressure）

- 定义：下游饱和时把「慢」信号传回上游，使生产速率 ≤ 消费速率。
- 实现形态：有界队列 + 阻塞 put、响应式 `request(n)`、TCP 窗口、Go 通道缓冲、
  信号量许可、`Semaphore` 限并发。
- 反模式：无界队列（把过载变成 OOM 与无界延迟）、丢弃却不计数、静默重试风暴。

## 限流算法

| 算法 | 特性 | 适用 |
|---|---|---|
| 固定窗口计数 | 简单，边界突刺 | 粗配额 |
| 滑动窗口 | 平滑，内存换精度 | 精确配额 |
| 漏桶 | 恒定速率输出 | 削峰整形 |
| 令牌桶 | 允许突发 | 常见 API 限流 |

## 过载保护配套

1. **超时**：每一跳都有 deadline，且总 deadline 递减传播（见 [取消与超时模式](../实践模式/取消与超时模式.md)）。
2. **舱壁隔离**：按依赖分池/分配额，一个慢依赖不耗尽全部线程。
3. **熔断**：连续失败即快速失败 + 半开探测；须与重试上限共存，否则重试放大故障。
4. **降级**：明确「丢什么」优先于「怎么排队」。
5. **观测**：队列深度、拒绝数、P99 等待、限流命中率为核心指标。
