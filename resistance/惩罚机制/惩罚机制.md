# 惩罚机制

失败计数与熔断，防止无意义重试消耗预算与制造噪声。

## 必须

1. 每次失败计数：`python -B scripts/penalty.py hit <节点> [原因]`。
2. 达 10 次即熔断（退出码 3）：强制回退本节点或求助用户，禁止继续第 11 次尝试。
3. 修复成功后清零：`python -B scripts/penalty.py reset <节点>`。
4. 计数状态落用户缓存目录，禁止写入 skill 目录。
5. 熔断时须同时记 `process_chain.py interrupt`，把最后一次失败证据附在 reason 里。

## 禁止

- 换个说法重复同一失败（计数照加，不得绕过）。
- 熔断后私自降级交付或跳过审查。
- 用 reset 掩盖未修复的失败。

## 违规后果

- 无限重试 → token 与时间双浪费，且掩盖真实缺陷；
- 绕过熔断 → 缺陷直接进入 main 分支发布。

## 兜底

- 求助用户模板：列出「已试方案 + 失败证据 + 两个候选下一步」，由用户拍板。
