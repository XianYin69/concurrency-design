# 锁与无锁数据结构

来源：[本地]（未联网确证）· 用途：同步机制选型与代价评估。

## 谱系（由粗到细）

| 机制 | 保证 | 代价 | 典型误用 |
|---|---|---|---|
| 全局大锁 | 简单正确 | 扩展性差 | 锁内做 IO/长循环 |
| 细粒度锁 | 并发度高 | 锁序复杂 | 死锁、伪共享 |
| 读写锁 | 读多写少 | 写饥饿 | 读临界区长 |
| 分段/条带锁 | 折中 | 跨段操作需多锁 | 跨段无原子性 |
| 自旋锁 | 短临界区 | 烧 CPU | 长等待、优先级反转 |
| 原子/CAS | 单字或可重试 | ABA、活锁 | 复合不变量 |
| 无锁队列/栈 | 进展保证 | 实现极难 | 内存回收（见 RCU） |
| 不可变/快照 | 读免锁 | 写放大 | 误以为写也免费 |

## 高频结论

1. 先证明「锁是瓶颈」再优化：给出争用指标（等待时间、上下文切换、P99），否则是猜测。
2. CAS 循环须有退避与进展保证；高争用下 CAS 失败率飙升，可能不如锁。
3. 无锁 ≠ 无同步：仍需内存序与回收协议，且**不自动消除竞态条件**（逻辑级）。
4. 伪共享：热点字段按缓存行（常见 64B）填充/分组，性能问题先查对齐。
5. 结构选型跟着访问模式走：读多→快照/COW；写多→分段；跨键一致→事务或单 owner。
