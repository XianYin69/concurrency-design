# 初始化

两条路径的共同前置步骤：建立工作空间与许可基线。

## 动作

1. 确认目标目录；未指定时在固定路径沙盒作业：`python -B scripts/sandbox.py create --name concurrency-design`。
2. 建立 tmp 工作镜像（生成文件一律入 tmp，禁止直写 skill 目录）。
3. 写入 MIT `LICENSE`（工作区根与 tmp 各一份，已有不覆盖）。
4. 检查仓库：无 `.git/` 即 `git init`（不得跳过），核对 `.gitignore` 含 `tmp/` 与 IDE 目录。
5. 挂载五大机制：逻辑链、过程链、上下文压缩、垃圾回收、惩罚。
6. 依赖自检：`python -B scripts/deps_check.py`（file_ops / code-guidelines / pavedpath-code / python / git）。
7. 运行时探测：确认目标语言/版本与可用检测工具（TSan/Helgrind/`-race`），缺失即记为依赖缺口。

## 产出

- `LICENSE`、`.gitignore`、功能分支 `feature/init`、`logic_chain.jsonl` 首条。

## 兜底

- 依赖缺失：记 `process_chain.py interrupt` 并报告缺项，禁止伪造能力继续。
- 沙盒创建失败：降级为 tmp 镜像作业，收尾时询问交付路径。
- 无竞态检测工具：降级为静态剖面 + 多轮压力复现，并声明「未经检测器确证」。
