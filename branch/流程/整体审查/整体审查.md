# 整体审查
九项标准全部通过才可进入收尾；任一失败记中断并回相应节点。
## 九项标准
1. 流程完整：创建/修改两条路径节点齐全，文件夹名=流程名。
2. 链接闭合：`python -B scripts/check_links.py --root .` 悬空链接 = 0。
3. 体量合规：所有 .md ≤ 50 行（50 行红线只约束 markdown 文本；脚本 .py/.ps1/.sh/.cmd 不限行数，但仍禁裸 except、print 调试残留、>100 字符长行、超长函数）（`lint_check.py`）。
4. 提示词合规：SKILL.md 含 YAML frontmatter；agent/ 四格式一句话提示词。
5. 依赖合规：`dependence/` 声明齐全且无内嵌他技能正文（`deps_check.py` 通过）。
6. 机制接入：五大机制脚本可用且被节点引用。
7. 约束有效：resistance/ 每条约束有违规后果与兜底，含三条领域约束
   （共享可变状态、锁粒度、取消安全）。
8. 代码可运行：构建测试报告全绿——静态剖面清零或有豁免理由、锁序环数 = 0、
   压测多轮 0 失败、取消/超时在 SLO 内收敛。
9. 知识沉淀：浏览器学习结论已入知识链与 references/，`[联网]`/`[本地]` 标注如实可溯。
## 动作
- 双链辩论：`logic_chain.py debate --pro <通过理由> --con <否决理由>`，裁决记链。
- 失败：`process_chain.py interrupt --step 整体审查 --reason <项>`，修复后 `resume`，重试 10 次熔断。
- 领域复核：逐条对照 [共享可变状态约束](../../../resistance/共享可变状态约束/共享可变状态约束.md)、
  [锁粒度约束](../../../resistance/锁粒度约束/锁粒度约束.md)、
  [取消安全约束](../../../resistance/取消安全约束/取消安全约束.md)，任一项无证据即判不通过。
