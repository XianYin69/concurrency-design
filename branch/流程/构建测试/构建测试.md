# 构建测试
竞态可查、锁序无环、取消能收敛才算完成，失败即回脚本构建。
## 动作
1. 预览：`python -B scripts/run_tests.py --path tmp/<proj> --dry-run`，确认后执行。
2. 静态剖面：`race_probe.py` + `thread_safety_lint.py` 清零或逐条给出豁免理由（记逻辑链）。
3. 锁序验环：`python -B scripts/deadlock_check.py tmp/locks.log` → 环数必须为 0。
4. 不变量测试：构造并发用例断言不变量（无丢失更新、无重复消费、计数守恒），
   并做「失败→修复」回归配对。
5. 压力复现：`stress_test_runner.py --target <mod> --fn <fn> --threads N --rounds M --timeout T --yes`
   多轮重复，记录失败率与挂起线程数。
6. 取消与超时：触发取消/超时，验证在 SLO 内收敛且资源释放、状态自洽。
7. 检测器（可用时）：TSan / `-race` / Helgrind / JCStress，命令与版本落档。
8. 失败处理：最小可复现片段 → `process_chain.py interrupt` → 回
   [脚本构建](../脚本构建/脚本构建.md) → `resume`。
## 产出
- `tmp/test-report.md`：用例数、通过率、压测失败率、锁序结论、检测器输出摘要。
- 逻辑链一条：测试结果 → 是否可交付的裁决。
## 兜底
- 无检测工具：降级为静态剖面 + 多轮压测，并明确声明「未经检测器确证」。
- 竞态无法复现：转 [浏览器学习](../浏览器学习/浏览器学习.md) 查时序植入/确定性调度方法，禁止猜测式反复改。
- 重试达 10 次：`penalty.py hit` 熔断，回退本步或求助用户。
