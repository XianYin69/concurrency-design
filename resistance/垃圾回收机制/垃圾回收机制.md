# 垃圾回收机制

约束 tmp 与缓存的生命周期，防止过程工件污染技能目录。

## 必须

1. 生成文件一律入 tmp（`env SMS_TMP`），禁止直写 skill 目录。
2. 收尾后先释放再删除：`python -B scripts/garbage_collect.py --path tmp --dry-run` 预览，
   `--yes` 执行。
3. 回收前确认目标 skill 已收到产物（`self_update.py compare` 比对一致）。
4. 未指定目标目录时按 [沙盒机制](../沙盒机制/沙盒机制.md) 交付后删除沙盒。
5. 过期判据：默认 7 天未修改的 tmp 文件视为可回收（`--age` 可调）。

## 禁止

- 在 skill 目录留 `.log`、`*.pyc`、`tmp/`、下载缓存。
- 未预览即删除（递归删除属高危，须 `--yes` + grant danger）。
- 删除 references/ 内已标注出处的知识条目（属知识资产，非垃圾）。

## 违规后果

- 缓存入库 → 技能体积膨胀、隐私外泄、安装端污染；
- 误删产物 → 交付丢失，须回退重跑整条流程。
