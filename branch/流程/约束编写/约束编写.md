# 约束编写
把本次执行中确立的规则固化进 `resistance/`，形成不可逾越的兜底。
## 动作
1. 识别红线区：见 [`约束部分`](../../../resistance/约束部分/约束部分.md) 的判定规则。
2. 编写：每条约束独立文件夹 + 同名 md，≤50 行，「必须/禁止」句式，附违规后果。
3. 领域约束必含三条：
   [共享可变状态约束](../../../resistance/共享可变状态约束/共享可变状态约束.md)（归属/同步/可见性）、
   [锁粒度约束](../../../resistance/锁粒度约束/锁粒度约束.md)（锁序无环/临界区最小/持锁有界）、
   [取消安全约束](../../../resistance/取消安全约束/取消安全约束.md)（超时/取消传播/幂等收尾）。
4. 合并：同类约束合并，冲突约束交 constraint_arbiter 仲裁，禁止互相覆盖。
5. 兜底：为每条约束写降级动作（回退/求助/熔断），无兜底的约束不得入库。
6. 优先级声明：正确性 > 活性 > 性能；任何为性能放宽前两者的条款须显式写明并附证据。
7. 登记：`CHANGELOG.md` 记变更；约束目录变更须经 update 审批流。
## 产出
- [`resistance/`](../../../resistance/resistance.md) 更新 + 逻辑链记录每条约束来源。
## 禁止
- 删除既有约束（红线）；只能新增或经审批修订。
- 写无兜底、无违规后果的空洞口号式约束。
- 为吞吐/延迟放宽共享状态、锁序或取消语义的门槛。
