# 约束部分（红线区识别规则）

定义「哪些内容属于受约束的红线区」，以及识别方法。

## 红线区清单

| 区域 | 路径 | 约束强度 |
|---|---|---|
| 约束本体 | `resistance/` | 最高：不得删除，改动须审批 |
| 许可与声明 | `LICENSE`、`dependence/` | 高：改动须记 CHANGELOG |
| 流程骨架 | `branch/流程/` | 高：节点不得缺失或改名 |
| 入口文档 | `SKILL.md` | 高：frontmatter 与红线不得破坏 |
| 机制脚本 | `scripts/` | 中：须语法可执行（脚本不计行数，50 行红线仅限 markdown） |
| 知识摘要 | `references/` | 中：须标来源，正文不得抄袭 |

## 识别规则

1. 文件含「必须 / 禁止 / 不得 / 红线」字样 → 属红线区。
2. 被 ≥2 个流程节点链接引用 → 属结构红线区，改动须全链复核。
3. 涉及网络、写盘、删除、推送 → 属高危区，须 grant 与预览。
4. 无法判定 → 按更严一级处理，并在逻辑链留判定理由。
