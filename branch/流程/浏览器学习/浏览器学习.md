# 浏览器学习
横切强制节点：任一步遇到不明（API/内存序/锁属性/取消语义/工具选项）**必须**联网学习后再继续。
## 触发条件
- 原子操作的默认内存序、`volatile`/`atomic` 保证范围、条件变量唤醒语义无法从本地资料确证。
- 版本行为存疑：Java 虚拟线程/`StructuredTaskScope` API 稳定性、C++ 标准库支持度、
  Python `TaskGroup` 起始版本、Go 调度器参数。
- 报错/现象不在已知模式内：`40P01` 类死锁码、TSan 报告含义、`pthread` 返回码、
  协程 pinning、通道 panic（关闭已关通道）。
- 涉及未用过的库/工具（liburcu、JCStress、loom、shuttle、tokio、netty、Disruptor 等）。
## 动作
1. 派 `file_ops` 技能（`local:skill_manage_system`）执行搜索/抓取：
   `python -B scripts/browser_learn.py --query "<问题>" --out tmp/learn`
   （内部走 ff_lite.py search/fetch，须 `:grant network`，未授权先申请）。
2. 取证：记录 URL、访问时间、**语言/运行时与版本号**、关键结论；只取事实不抄正文。
3. 蒸馏：结论写入知识链（`chain append` knowledge 链）+ `references/<领域>/<主题>.md`，
   来源改标 `[联网]`。
4. 回原节点继续，并在逻辑链记「因 X 不明 → 学习 → 采用 Y」。
## 禁止
- 未学习即凭记忆写 API、解释报错或断言某版本内存模型行为。
- **跨语言类推**：把 Java `volatile` 语义套到 C++/Go，或把 x86 硬件序当成语言级保证。
- 学习结论不落链、不复用（重复浪费）。
- 无网络授权时伪造检索结果或编造 URL。
