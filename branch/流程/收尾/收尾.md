# 收尾

交付、提示词核对、git 合入、垃圾回收，然后标记「完成」返回调度方。

## 动作

1. 提示词核对：SKILL.md frontmatter + `agent/` 四格式（CLAUDE.md / .cursorrules /
   instructions.md / agent_prompt.md）均为一句话「使用 concurrency-design 来完成用户请求」。
2. 交付：`python -B scripts/sandbox.py deliver --id <沙盒> --to <目标目录> --yes`（默认预览）。
3. git 工作流（见 [git工作流约束](../../../resistance/git工作流约束/git工作流约束.md)）：
   各 `feature/<topic>` 辩论+悬空链接=0 后合入 `dev`；九项审查通过后 `dev` 合入 `main`；
   **推送前必须询问用户**，确认后才 `git push origin main dev`。
4. 垃圾回收：`garbage_collect.py --path tmp --dry-run` 预览后清理，tmp 释放即删。
5. 自更新比对：`self_update.py report` 记录版本与变更。
6. 标记「完成」，收口返回 SMS 主流程由其整合续排（本步完成≠整段任务结束）。

## 禁止

- 直写 main/dev；跳过功能分支；未经用户确认推送远端。
- 把缓存/临时产物留在 skill 目录。
