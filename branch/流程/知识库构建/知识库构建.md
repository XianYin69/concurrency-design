# 知识库构建
把本次任务所需的外部知识沉淀进 `references/`，拓扑至不可再出新领域为止。
## 动作
1. 选题（并发七域）：理论（内存模型/happens-before、竞态与数据竞争、死锁四条件）+
   书目（Java 并发编程实战、C++ 并发编程实战、多处理器编程艺术、POSIX 线程）+
   执行模型（线程池与工作窃取、事件循环与 async/await、Actor 与 CSP、协程）+
   数据结构（锁与无锁、ABA 与 RCU）+ 并发控制（事务隔离级别、背压与限流）+
   实践模式（取消与超时、结构化并发）+ 工具与检测（TSan/Helgrind/JCStress、压测复现）。
2. 抓取：`python -B scripts/knowledge_fetch.py --url <白名单页> --out tmp/downloads`
   （白名单：wikipedia / open-std.org（ISO C++、POSIX）/ java.sun.com·docs.oracle.com /
   go.dev / rust-lang.org / python.org / github / stackoverflow / *.org；须 `:grant network`）。
3. 转换：`knowledge_convert.py` 把 HTML 转 md 摘要，**只存摘要与出处，不存版权正文**。
4. 落库：`references/<领域>/<主题>.md`，每文件 ≤50 行，含来源标注：
   `[联网]` = 可溯 URL；`[本地]` = 模型既有常识未经联网确证（须先经浏览器学习确证再落实现）。
5. 拓扑判据：新主题能引出未覆盖的相邻领域 → 继续；引不出 → 收口并写明缺口归属
   （GPU 并行、分布式共识、实时调度、形式化验证等按需触发）。
## 产出
- [`references/references.md`](../../../references/references.md) 索引 + 七域子目录。
## 兜底
- 网络不可用（如本次 urlopen 10060）：降级为 `[本地]` 标注 + 向用户说明缺口，
  禁止编造文献内容或伪造 URL。
- 缓存文件禁止写入 skill 目录（一律落用户缓存目录 / tmp）。
