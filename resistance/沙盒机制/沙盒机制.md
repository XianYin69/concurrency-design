# 沙盒机制

未指定目标工作目录时，在固定路径建沙盒作业，交付后删除沙盒。

## 必须

1. 建沙盒：`python -B scripts/sandbox.py create --name concurrency-design`
   （根路径 `<SMS_HOME>/sandbox/`，登记 index.json）。
2. 所有生成文件先落沙盒 tmp，禁止直接写客户端 skills 目录。
3. 交付：`sandbox.py deliver --id <沙盒> --to <目标目录>` 默认预览，
   用户当轮确认 + `--yes` 才复制；覆盖既有文件须 grant danger。
4. 交付后 `self_update.py compare` 校验一致，再 `sandbox.py clean --id <沙盒> --yes`。
5. `sandbox.py list` 须在收口前确认无遗留沙盒。

## 禁止

- 未预览即复制/覆盖用户目录内容。
- 沙盒内留缓存、日志、下载物随交付一起复制（先按垃圾回收清理）。
- 交付后不删沙盒（残留会污染下次作业）。

## 违规后果

- 直写目标目录 → 半成品技能被 SMS 加载，路由到坏技能；
- 未确认覆盖 → 用户既有技能被毁，不可恢复。
